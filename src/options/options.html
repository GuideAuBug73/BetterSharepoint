Mode compact

Éléments à masquer quand le mode compact est actif :

Sélecteurs CSS supplémentaires à masquer, un par ligne. Le plus simple : dans SharePoint, Ctrl+K puis « Masquer un élément de la page… » et clique sur l’élément.

Raccourcis clavier

Clique sur un raccourci puis appuie sur la nouvelle combinaison. Retour arrière pour le désactiver, Échap pour annuler.

Favoris

Les favoris sont synchronisés par ton navigateur. Tu peux aussi les exporter pour les copier vers un autre navigateur.

Confidentialité

L’extension ne contacte que les sites SharePoint que tu visites, avec ta propre session. Aucune donnée n’est envoyée ailleurs. Favoris, récents et réglages restent dans le stockage de ton navigateur.
